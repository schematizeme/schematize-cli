CMD schematize
  SOBRE Ecosystem manager for Claude — skills, overdev, and more (Linux-first).
CMD schematize agent
  SOBRE Resident agent: periodically checks and notifies (used by autostart)
CMD schematize apps
  SOBRE Apps do ecossistema: quais existem, quais estão instalados, e INSTALAR de fato
CMD schematize apps exec
  SOBRE Forward a command to the app, inheriting the terminal and the exit code. Ex.: schematize apps exec optimizer -- diag
  ARG app                   OBRIGATORIO
  ARG args                  <valor>
CMD schematize apps install
  SOBRE Actually INSTALL an ecosystem app (builds from source; takes minutes)
  ARG app                  
  ARG yes                  --yes
CMD schematize autostart
  SOBRE Bind the agent to the system (starts at login)
CMD schematize autostart disable
  SOBRE Disable and remove the autostart
CMD schematize autostart enable
  SOBRE Enable and start the agent (systemd --user + XDG autostart)
CMD schematize blog
  SOBRE Open the blog (blog.schematize.net) in the browser
CMD schematize check
  SOBRE Check for updates once (with --notify, fire a desktop notification)
  ARG notify               --notify
CMD schematize debug
  SOBRE Debug the update manager/versioning; or --collect a shareable, secret-safe debug report
  ARG collect              --collect
  ARG online               --online
  ARG out                  --out
  ARG stdout               --stdout
CMD schematize deployer
  SOBRE Deployer: o app de SSH/VPS, separado (ADR-0010). Instalar, ver estado e repassar comandos
CMD schematize deployer exec
  SOBRE Repassa tudo depois do `--` ao deployer, herdando o terminal e o código de saída. Ex.: schematize deployer exec -- vps list
  ARG args                  <valor>
CMD schematize deployer install
  SOBRE Show how to install the deployer on this machine
CMD schematize deployer status
  SOBRE O deployer está instalado? Em que versão e onde?
CMD schematize diagnostics
  SOBRE Envia (OPT-IN) o relatório de diagnóstico REDIGIDO pro servidor (POST /diagnostics). Nada é enviado por padrão — só com este comando e após confirmar
  ARG yes                  --yes
CMD schematize disco
  SOBRE Inventário e limpeza do lixo recriável: artefato de build, cache de toolchain e camada de Docker — agrupado por DISCO (é o principal que costuma encher)
CMD schematize disco clean
  SOBRE Apaga os artefatos que casam com os filtros (mostra a lista antes)
  ARG min_dias             --min-dias
  ARG montagem             --montagem
  ARG tipo                 --tipo
  ARG yes                  --yes -y
CMD schematize disco docker
  SOBRE Uso e podas do Docker
  ARG podar                --podar
  ARG yes                  --yes -y
CMD schematize disco list
  SOBRE Lista o que dá pra recuperar, agrupado por DISCO e por tipo
  ARG min_dias             --min-dias
CMD schematize doctor
  SOBRE Diagnose the environment (add --fix to repair what's safe)
  ARG fix                  --fix
CMD schematize gui
  SOBRE Open the graphical window (same software as the CLI — just the GUI face)
CMD schematize icon (oculto)
  SOBRE Gera o ícone do app EM CÓDIGO (resiliente — sem rasterizar SVG). `--emit <png>` um tamanho; `--hicolor <dir>` a árvore freedesktop inteira (16..512). Usado pelo install.sh
  ARG emit                 --emit
  ARG hicolor              --hicolor
  ARG size                 --size
CMD schematize lang
  SOBRE Get/set the interface language (no args = show current; --list = all)
  ARG code                 
  ARG list                 --list
CMD schematize login
  SOBRE Log in to the schematize platform via the browser (OAuth device flow)
CMD schematize logout
  SOBRE Log out (delete the local session)
CMD schematize news
  SOBRE Show the latest posts from blog.schematize.net
CMD schematize notifications
  SOBRE Show aggregated notifications (app update, blog posts, outdated skills), grouped by scope
  ARG concluir             --concluir
  ARG historico            --historico
  ARG lidas                --lidas
  ARG sync                 --sync
CMD schematize open
  SOBRE Open a resource in the browser: site | blog | github
  ARG target                OBRIGATORIO
CMD schematize projects
  SOBRE Projects: list detected/pinned projects, pin/unpin, or drop a `.schematize` marker
CMD schematize projects add
  SOBRE Pin a folder as a first-class project (always listed, even without a git marker)
  ARG path                  OBRIGATORIO
CMD schematize projects list
  SOBRE List every project (pinned + detected from the dev dirs), flagging the pinned
CMD schematize projects mark
  SOBRE Drop a `.schematize` marker file in the folder (default: cwd) → a project that stops the scan from descending (turns an umbrella into ONE project)
  ARG path                 
CMD schematize projects remove
  SOBRE Unpin a previously pinned folder
  ARG path                  OBRIGATORIO
CMD schematize projects unmark
  SOBRE Remove the `.schematize` marker from the folder (default: cwd)
  ARG path                 
CMD schematize status
  SOBRE Overview dashboard: versions, agent, overdev, language, links
CMD schematize upgrade
  SOBRE Update schematize itself — atualiza o próprio schematize (o APP, o binário), não as skills
  ARG force                --force
CMD schematize whoami
  SOBRE Show who is logged in (the account subject)
